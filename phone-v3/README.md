# 휴대폰 이야기 페이지 v3

잠금 해제 → 5분 동안 알림·문자·전화가 쏟아지고 → 배터리가 닳아 폰이 꺼지는 인터랙티브 콘텐츠예요.
**이야기는 `story.js` 하나만 고치면 됩니다.** (`app.js`, `style.css`, `index.html`은 건드리지 않아도 돼요.)

## 1. 쓰던 폴더에 적용하기
1. 쓰던 폴더에서 `story.js`를 **다른 이름으로 복사해 두세요.** (백업, 예: `story-옛날.js`)
2. 새 파일 4개(`index.html`, `style.css`, `app.js`, `story.js`)를 쓰던 폴더에 **덮어쓰기** 하세요.
3. `images` 폴더(사진)는 그대로 두세요. 덮어쓰지 않아요.
4. `index.html`을 더블클릭해서 열면 끝이에요. 수정 후엔 F5.

새 `story.js`에는 지금까지 쓰신 이야기(등장인물, 문자, 통화 기록, 사진, 메모, 검색 기록)가 모두 들어 있어요.
**【샘플】**이라고 적힌 곳은 제가 예시로 채운 내용이니 자유롭게 바꾸거나 지우세요.

## 2. 새로 생긴 것
| 기능 | story.js 에서 |
|---|---|
| 배터리가 닳아 일정 시간 뒤 화면이 꺼짐 | `battery`(시작 %), `playTime`(켜져 있는 시간, 초. 300 = 5분) |
| 꺼진 뒤 엔딩 화면과 "처음부터 다시" 버튼 | `ending` |
| 여러 사람이 여러 번 거는 전화 | `events` 의 `type: "call"` + `retry` |
| 못 받은 전화에 남는 음성 메시지(글) | 통화 사건의 `voicemail` |
| 꺼지기 직전 모르는 번호의 마지막 전화 | `at: "end-50"`, `final: true`, 대사의 `cut: true` |
| 인터넷(기사, 댓글, 검색, 즐겨찾기) | `web`, `history` |
| 음악(곡 목록, 재생 화면, 가사) | `music` |
| 캘린더(달력 + 일정), 시계(알람) | `calendar`, `alarms` |
| 잠긴 메모(암호 입력) | 메모의 `lock`, `hint` |
| 사진 문자 | `texts` 안에 `{ img: { color: "#9aa5c4" }, text: "…" }` |
| 사진 즐겨찾기 / 삭제된 사진 | 사진의 `favorite: true`, `deleted: true` |

## 3. 전화 만들기 (가장 중요)
```js
{ id: "yurimCall", at: 5, type: "call", from: "yurim", ring: 20,
  retry: { times: 2, every: 18 },          // 안 받으면 18초 뒤 또 걸려옴 (최대 2번 더)
  lines: [
    { who: "them", text: "여보세요? 최수현?" },
    { who: "me",   text: "…응." }
  ],
  voicemail: "끝까지 못 받으면 사서함에 남는 말",
  onMiss: "다음사건id", onDecline: "다음사건id" }
```
- 받으면 대사가 글로 한 줄씩 나와요. 화면을 누르면 바로 다음 대사로 넘어가요.
- 전화가 겹치면 줄을 서서 차례로 와요.
- **마지막 전화**: `at: "end-50"`(꺼지기 50초 전) + `final: true`. 다른 전화를 밀어내고 먼저 오고, 이 통화가 끝나면 폰이 꺼져요.
  마지막 대사에 `cut: true`를 쓰면 그 대사를 보여준 직후 통화 중에 뚝 꺼져요.
- 시간을 한눈에 보려면: 5분(300초) 동안 사건을 `at: 5`, `at: 28`, `at: 62` … 처럼 배치하세요.

## 4. 답장 규칙 (문자)
```js
replies: [
  { match: ["그래서"], after: "knowsSecret", say: ["너한테만 말하는 건데", "사실 나 이사 가"] },
  { match: ["비밀"], say: ["무슨 비밀?", "궁금하면 '그래서'라고 해봐"], set: "knowsSecret" }
],
fallback: ["응?", "그래"]
```
- 위에서부터 보고 **맞는 첫 번째 규칙 하나**만 쓰여요. 조건이 까다로운 규칙을 위에 두세요.
- `say`에 문장을 여러 개 쓰면 끊어서 연달아 와요. `delay`(첫 답 대기), `gap`(문장 사이 간격)을 초 단위로 조절해요.
- `set`은 표시를 남기고, `after`는 그 표시(또는 사건 id)가 있을 때만 규칙을 써요.
- `then: "사건id"`를 쓰면 답장 뒤에 전화나 다른 문자가 이어져요.

## 5. 인터넷
- `web.pages` 에 기사/게시글을 적어요. 본문은 글(문단), `{ h: "소제목" }`, `{ quote: "인용" }`, `{ img: "#색" 또는 "images/사진.jpg", caption: "설명" }`.
- `comments` 에 댓글, `tags` 에 검색에 걸릴 단어, `visited: true` 면 "최근 방문"에 나와요.
- 인터넷 앱 아래 입력칸에 직접 검색하면 제목, 태그, 본문에서 찾아서 보여줘요.
- 사이트 이름과 주소는 실제 언론사/사이트와 겹치지 않게 지어낸 이름을 쓰세요.

## 6. 사진·음악 파일 넣기
- 사진: 폴더에 `images` 만들고 `src: "images/photo1.jpg"` (확장자도 똑같이).
- 음악: 폴더에 `audio` 만들고 곡에 `src: "audio/song1.mp3"`. 없으면 잔잔한 배경음(`ambient`)이 나와요.
  저작권이 있는 음악은 공개 인터넷에 올리면 문제가 될 수 있어요. 직접 만든 곡이나 허락받은 곡을 쓰세요.

## 7. 테스트 팁
- `speed: 6` 처럼 올리면 6배 빠르게 진행돼요(5분이 50초). **완성 후엔 반드시 1로.**
- 처음부터 다시 보려면 F5.
- 화면이 하얗게 나오면 `story.js`의 따옴표(`"`)나 쉼표(`,`)가 빠졌을 확률이 높아요. 브라우저에서 `F12` → Console의 빨간 글씨가 몇 번째 줄인지 알려줘요.
- 글 안에서 줄을 바꾸려면 엔터가 아니라 `\n` 을 쓰세요.

## 8. 인터넷에 올리기 (GitHub Pages, 무료)
1. github.com 가입 → 새 저장소(Public) 만들기.
2. 폴더 안의 파일과 `images`, `audio` 폴더를 모두 업로드.
3. `Settings` → `Pages` → Branch `main` / `(root)` → Save.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 생겨요.

> 공개 저장소에 올린 파일은 누구나 볼 수 있어요. 비밀번호도 코드에서 보이니, 이야기 속 재미 요소로만 생각해주세요.
